# Учебная АТС `sip_pbx` — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Registrar + stateful SIP proxy (RFC 3261 §16–17) на Elixir/OTP 27: регистрация с digest, вызов/разговор/отбой через АТС, CANCEL, 404 на незарегистрированного, веб-консоль.

**Architecture:** один UDP-сокет `Transport` демультиплексирует по branch; транзакция = процесс (`TxServer`/`TxClient`, GenServer под temporary-супервизором, честные таймеры §17 из env); `Proxy` — стейт-машина маршрутизации с DialogStore/CallTracker (плечи A/B); консоль (Cowboy 8420) читает только PubSub/REST, ядро про неё не знает.

**Tech Stack:** Elixir 1.19 / OTP 27; deps: `plug_cowboy`, `jason`, `websock_adapter`; dev: `ex_doc`, `dialyxir`, `credo`.

**Spec:** `docs/superpowers/specs/2026-11-03-sip-pbx-design.md` (в этом репозитории) — аргументация решений там, здесь только исполнение.

## Global Constraints

- Elixir 1.19 / OTP 27; комментарии и документы — по-русски; доменные термины (INVITE, digest, nonce, CSeq, binding, AOR) не переводить; call leg — **плечо** (A/B).
- Транспорт — только UDP. Боевые порты: SIP **5060** (`SIP_PBX_SIP_PORT`), веб **8420** (`SIP_PBX_WEB_PORT`); в `config/test.exs` — свои (SIP **5160**, веб **8421**), чтобы тесты не мешали `./run.sh`.
- Таймеры §17 из Application env: `t1_ms` (боевой 500; в тесте **20**), `t2 = 8·t1`, транзакция живёт `64·t1`.
- Digest MD5 (RFC 2617): REGISTER → `401/WWW-Authenticate`, INVITE → `407/Proxy-Authenticate`; nonce stateless HMAC-SHA256, свежесть 5 мин (просрочен → `stale=true`), `nc` строго растёт на пару (nonce, username).
- Антибрутфорс: >10 неуспешных digest с IP за 30 с → дроп трафика с IP на 15 мин + алерт `auth_burst`; разбан — только командой консоли.
- Команд управления в консоли **ровно три**: снять абонента с регистрации; разблокировать IP; убить зависшую транзакцию.
- Пользователи статические `config/users.exs`: 1001, 1002, 1003 (1003 — «незанятый»).
- На входящих не придираемся: cookie `z9hG4bK` у чужих branch не проверяем, компактные имена раскрываем; свои branch — только с cookie.
- Каждый код отказа (§6 матрица) — событие журнала и метрик. После отбоя/отказа — реестр транзакций и DialogStore пусты (инвариант «без зависшего вызова», ассерт в тестах).
- Gates каждого коммита: `mix format --check-formatted`, `mix test`, `mix credo --strict`, `ERL_LIBS=/opt/erlang-27/lib/erlang/lib mix dialyzer`. `@moduledoc`/`@doc`/`@spec` — по стандарту документации корневого CLAUDE.md; документация — в том же коммите, что код.
- Коммиты — из `sip_pbx/` (это отдельный git-репозиторий, main уже инициализирован).

`lib/sip_pbx/sip/digest.ex`:

```elixir
defmodule SipPbx.SIP.Digest do
  @moduledoc """
  HTTP digest (RFC 2617) для SIP-аутентификации: stateless nonce на HMAC-SHA256,
  пересчёт digest, разбор/сборка заголовков. Чистые функции — время и секрет
  приходят аргументами, чтобы тесты не зависели от процессов.
  """

  @doc """
  Stateless nonce: `base64url("ms|ip|hmac")`. Подпись привязана к IP — чужой
  украденный nonce не переиспользуется.

  ## Examples

      iex> String.contains?(SipPbx.SIP.Digest.nonce("s", {127, 0, 0, 1}, 123), "127.0.0.1")
      true

  """
  @spec nonce(binary(), :inet.ip_address(), integer()) :: String.t()
  def nonce(secret, ip, ms) do
    payload = "#{ms}|#{:inet.ntoa(ip)}"
    mac = mac_of(secret, payload)
    Base.url_encode64(payload <> "|" <> mac, padding: false)
  end

  @doc "Проверка подписи, принадлежности IP и свежести; просроченный — `:stale`."
  @spec check_nonce(binary(), :inet.ip_address(), String.t(), integer(), integer()) ::
          :ok | {:error, :stale | :bad}
  def check_nonce(secret, ip, encoded, now_ms, lifetime_ms) do
    with {:ok, decoded} <- Base.url_decode64(encoded, padding: false),
         [ms_s, ip_s, mac] <- String.split(decoded, "|", parts: 3),
         true <- eq?(mac, mac_of(secret, "#{ms_s}|#{ip_s}")),
         true <- ip_s == to_string(:inet.ntoa(ip)),
         {ms, ""} <- Integer.parse(ms_s) do
      if now_ms - ms > lifetime_ms, do: {:error, :stale}, else: :ok
    else
      _ -> {:error, :bad}
    end
  end

  @doc """
  MD5 digest. `nc/cnonce` — при `qop=auth`, иначе `nil` (классическая форма).

  ## Examples

      iex> SipPbx.SIP.Digest.response("Mufasa", "testrealm@host.com", "Circle Of Life",
      ...>   "GET", "/dir/index.html", "dcd98b7102dd2f0e8b11d0f600bfb0c093", nil, nil)
      "6629fae49393a05397450978507c4ef1"

  """
  @spec response(String.t(), String.t(), String.t(), String.t(), String.t(), String.t(),
                String.t() | nil, String.t() | nil) :: String.t()
  def response(username, realm, password, method, uri, nonce, nc, cnonce) do
    a1 = md5("#{username}:#{realm}:#{password}")
    a2 = md5("#{method}:#{uri}")

    raw =
      if is_nil(nc) or is_nil(cnonce) do
        "#{a1}:#{nonce}:#{a2}"
      else
        "#{a1}:#{nonce}:#{nc}:#{cnonce}:auth:#{a2}"
      end

    md5(raw)
  end

  @doc "Значение `WWW-Authenticate`/`Proxy-Authenticate`; `opts: [stale: true]` — после протухания nonce."
  @spec challenge_header(String.t(), String.t(), String.t(), keyword()) :: String.t()
  def challenge_header(realm, nonce, opaque, opts \\ []) do
    stale = if opts[:stale], do: ", stale=true", else: ""

    ~s(Digest realm="#{realm}", nonce="#{nonce}", opaque="#{opaque}", ) <>
      ~s(qop="auth", algorithm=MD5#{stale})
  end

  @doc "Разбор значения `Authorization`/`Proxy-Authorization` в карту атом-ключей."
  @spec parse_auth(String.t()) :: {:ok, map()} | :error
  def parse_auth("Digest " <> rest) do
    pairs =
      for [_, k, v] <- Regex.scan(~r/([A-Za-z-]+)=("[^"]*"|[^,\s]+)/, rest) do
        {String.to_atom(k), String.trim(v, ~s("))}
      end

    m = Map.new(pairs)

    if Map.has_key?(m, :username) and Map.has_key?(m, :response) do
      {:ok, m}
    else
      :error
    end
  end

  def parse_auth(_), do: :error

  @doc """
  Сверка Authorization: сначала callback проверки nonce (`Auth` передаёт свою
  проверку свежести/подписи/nc), затем пересчёт digest — ответы не подсказывают,
  что именно не так.
  """
  @spec verify(map(), String.t(), String.t(), (map() -> :ok | {:error, term()})) ::
          :ok | {:error, :stale | :bad_nonce | :bad_digest}
  def verify(auth, password, method, nonce_check) do
    with :ok <- required_fields(auth),
         :ok <- nonce_check.(auth) do
      got =
        response(auth.username, auth.realm, password, method, auth.uri, auth.nonce,
          auth[:nc], auth[:cnonce])

      if eq?(got, auth.response), do: :ok, else: {:error, :bad_digest}
    else
      {:error, reason} -> {:error, reason}
    end
  end

  defp required_fields(auth) do
    needed = [:username, :realm, :nonce, :uri, :response]

    if Enum.all?(needed, &Map.has_key?(auth, &1)), do: :ok, else: {:error, :bad_nonce}
  end

  defp mac_of(secret, payload),
    do: :crypto.mac(:hmac, :sha256, secret, payload) |> Base.encode16(case: :lower)

  defp md5(s), do: :crypto.hash(:md5, s) |> Base.encode16(case: :lower)

  # сравнение без утечки длины через преждевременный выход
  defp eq?(a, b) when is_binary(a) and is_binary(b) do
    byte_size(a) == byte_size(b) and :crypto.hash(:sha256, a) == :crypto.hash(:sha256, b)
  end

  defp eq?(_, _), do: false
end
```

```elixir
  @doc "Полный REGISTER-цикл: 401 → digest-повтор в том же диалоге → 200."
  def register(sock, target, number, password, opts \\ []) do
    expires = Keyword.get(opts, :expires, 300)
    call_id = "reg-" <> rand_hex(6)
    tag = rand_hex(4)
    cseq = Keyword.get(opts, :cseq_start, 1)
    realm = Keyword.get(opts, :realm, "pbx.local")

    first = register_raw(number, realm, call_id, tag, cseq, expires, nil)
    send(sock, target, Message.to_binary(first))

    case recv(sock, Keyword.get(opts, :timeout, 2000)) do
      {:ok, %Message{status_code: 401} = ch} ->
        {nonce, realm} = challenge_fields(ch, "www-authenticate")
        auth = digest_header(first, password, {nonce, realm}, "authorization")

        second =
          first
          |> Message.put_header("cseq", "#{cseq + 1} REGISTER")
          |> Message.put_header("authorization", auth)

        send(sock, target, Message.to_binary(second))
        recv(sock, Keyword.get(opts, :timeout, 2000))

      other ->
        other
    end
  end

  defp register_raw(number, realm, call_id, tag, cseq, expires, _auth) do
    %Message{type: :request, method: "REGISTER", uri: "sip:#{number}@#{realm}", headers: [
      {"via", "SIP/2.0/UDP 127.0.0.1:#{rand_port()};branch=z9hG4bK" <> rand_hex(8)},
      {"from", "<sip:#{number}@#{realm}>;tag=#{tag}"},
      {"to", "<sip:#{number}@#{realm}>"},
      {"call-id", call_id},
      {"cseq", "#{cseq} REGISTER"},
      {"contact", "<sip:#{number}@127.0.0.1:55555;transport=udp>"},
      {"expires", "#{expires}"},
      {"content-length", "0"}
    ]}
  end

  @doc "Достаёт {nonce, realm} из заголовка challenge."
  def challenge_fields(msg, header) do
    with v when is_binary(v) <- Message.header(msg, header),
         {:ok, auth} <- SipPbx.SIP.Digest.parse_auth(v) do
      {auth["nonce"], auth["realm"]}
    else
      _ -> {nil, nil}
    end
  end

  @doc "Считает Authorization/Proxy-Authorization для повтора запроса."
  def digest_header(req, password, {nonce, realm}, _scheme_header) do
    [username] = Regex.run(~r/<sip:(\d+)@/, Message.header(req, "from") || "", capture: :all_but_first)
    nc = "00000001"
    cnonce = rand_hex(8)
    uri = req.uri

    resp =
      SipPbx.SIP.Digest.response(username, realm, password, req.method, uri, nonce, nc, cnonce)

    ~s(Digest username="#{username}",realm="#{realm}",nonce="#{nonce}",uri="#{uri}",) <>
      ~s(qop=auth,nc=#{nc},cnonce="#{cnonce}",response="#{resp}")
  end

  defp rand_port, do: 50_000 + :rand.uniform(10_000)
```

- `BYE`: `find_in_dialog(call_id, from_tag, to_tag)` → nil → IST (`kind: :other`) → `481`; иначе IST на входящем BYE + форвард копии второму плечу (`{:n, cid}`, `TxClient :other`); `{:tx_resp, {:n, cid}, 200}` → `respond(bye_ist, resp_down(200), true)`, `DialogStore.delete`, `CallTracker.finish(:hangup, nil)`, `Metrics.incr(:bye_done)`.
- `CANCEL`: `Transport.lookup_tx({:srv, branch_CANCEL_матча? нет — CANCEL матчится по branch+методу+CSeq исходного INVITE: {:srv, branch, "INVITE", cseq, from}})` — branch берём из верхнего Via CANCEL'а, cseq из CSeq CANCEL; IST nil → IST для CANCEL → `481`; иначе IST-CANCEL (`kind: :other`) → `200` на CANCEL; форвард CANCEL в B (`{:c, cid}`, `TxClient :other`); `{:tx_resp, {:c, cid}, 487}` → `respond(invite_ist_a, 487_down, true)` (A ответит ACK → обычная ветка `{:tx_acked}` чистит диалог), `CallTracker.finish(:canceled, 487)`, `:cancel_done`. Если B ответил 2xx **раньше** (§16.5): 200 уже доставлен A — CANCEL всё равно получает `200`, диалог остаётся active; BYE — ответственность телефонов (инвариант: диалог закроется BYE).
- `{:tx_timeout, {:b, cid}}` → `respond(a_tx, 408_down, true)`, `:call_fail`, `tx_timeout` метрика, таймер B-f.
- `{:sip_new_request, %Message{method: "ACK"} = ack, from}` (ACK с новым branch — так шлют ACK на non-2xx): сверка с DialogStore по call-id; есть незавершённый диалог с IST-A → форвард ACK плечу B (target `leg_b.target`, свой Via) + `TxServer.external_ack(a_tx)` (чистка — в штатной ветке `{:tx_acked}`); иначе журнал/дроп.
- Финальный ответ на **non-INVITE** в плече B (`{:n}`, `{:c}`) — до `TxClient.stop` отправить в B ACK (тот же branch: non-INVITE ACK сохраняет branch запроса) — иначе IST-CANCEL/IST-BYE собеседника висят до Timer D.
- `{:tx_dup, req, from}` (не ACK — дубликат уже мёртвой IST) — журнал, игнор (идемпотентность).
- Чужие методы → `405` (`Allow`), OPTIONS → `200`+`Allow`; ACK вне контекста (осиротевший) — журнал, дроп.

```elixir
  defp register_from(sock, target, num, pass, opts \\ []) do
    {:ok, p} = :inet.port(sock)

    case UAC.register(sock, target, num, pass, contact_port: p) do
      {:ok, _} -> :ok
      {:error, {:status, c, _}} -> flunk("регистрация #{num}: #{c}")

        {"via", "SIP/2.0/UDP 127.0.0.1:#{rand_port()};branch=z9hG4bK" <> UAC.rand_hex(8)},

    case UAC.recv(sock, 2000) do
      {:ok, %Message{status_code: 407} = ch} ->

        {drain_100(sock), Message.branch(second)}

    end
```
